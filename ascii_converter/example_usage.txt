ASCII CONVERTER - EXAMPLE USAGE
================================

1. BASIC CONVERSION
   ----------------
   Convert image to ASCII PNG (1:1 scale):
   
   python image_to_ascii.py planet_earth.jpg


2. HIGH-RES PLANET TEXTURES
   -------------------------
   For 4K source images, scale down for performance:
   
   python image_to_ascii.py earth_4k.jpg -o ascii_earth.png --scale 0.5


3. DIFFERENT CHARACTER STYLES
   ---------------------------
   Detailed (70 chars):
   python image_to_ascii.py sun.jpg --charset detailed
   
   Simple (10 chars):
   python image_to_ascii.py mars.jpg --charset simple
   
   Blocks (solid look):
   python image_to_ascii.py jupiter.jpg --charset blocks


4. PREVIEW IN BROWSER
   ------------------
   Generate HTML to preview before making large PNG:
   
   python image_to_ascii.py venus.jpg -f html
   (Open venus_ascii.html in browser)


5. CUSTOM SIZING
   -------------
   Make larger characters for dome visibility:
   
   python image_to_ascii.py saturn.jpg --char-width 10 --char-height 20


6. BATCH PROCESS PLANETS
   ----------------------
   Use the batch script:
   
   1. Place all planet textures in "input" folder
   2. Run: convert_planets.bat
   3. Find ASCII versions in "output" folder


7. COMPLETE EXAMPLE: EARTH
   ------------------------
   python image_to_ascii.py earth_texture.jpg ^
       -o ascii_earth.png ^
       --scale 0.5 ^
       --charset detailed ^
       --char-width 8 ^
       --char-height 16 ^
       --bg-color 0,0,0


8. COMPLETE EXAMPLE: SUN
   ----------------------
   python image_to_ascii.py sun_texture.jpg ^
       -o ascii_sun.png ^
       --scale 0.4 ^
       --charset blocks ^
       --char-width 10 ^
       --char-height 20 ^
       --bg-color 10,5,0


9. MEMORY-EFFICIENT (HUGE IMAGES)
   -------------------------------
   For 8K+ images, scale down significantly:
   
   python image_to_ascii.py huge_image.jpg --scale 0.25


10. COLOR BACKGROUNDS
    -----------------
    Dark red background for Mars theme:
    python image_to_ascii.py mars.jpg --bg-color 20,5,5
    
    Dark blue for Neptune:
    python image_to_ascii.py neptune.jpg --bg-color 5,5,20


RECOMMENDED SETTINGS FOR DIGISTAR PLANETS:
==========================================

Sun (bright, blocky):
    --scale 0.4 --charset blocks --char-width 10 --char-height 20

Mercury (detailed, small):
    --scale 0.5 --charset detailed --char-width 6 --char-height 12

Venus (simple, cloudy):
    --scale 0.5 --charset simple --char-width 8 --char-height 16

Earth (detailed, colorful):
    --scale 0.5 --charset detailed --char-width 8 --char-height 16

Mars (detailed, red):
    --scale 0.5 --charset detailed --char-width 8 --char-height 16

Jupiter (detailed, bands):
    --scale 0.4 --charset detailed --char-width 8 --char-height 16

Saturn (simple, with rings):
    --scale 0.5 --charset simple --char-width 8 --char-height 16

Uranus/Neptune (blocks, ice giants):
    --scale 0.5 --charset blocks --char-width 8 --char-height 16

DIGISTAR INTEGRATION:
====================

After conversion, copy files to:
    $Content\User\Textures\ASCII_Planets\

In Digistar script (.ds):
    # Apply ASCII texture to Earth
    Earth modelTexture $Content\User\Textures\ASCII_Planets\ascii_earth.png
    
    # Create custom sphere with ASCII texture
    myPlanet is solidModelClass
    myPlanet model $Software\Models\Primitives\sphere.x
    myPlanet modelTexture $Content\User\Textures\ASCII_Planets\ascii_mars.png
    myPlanet color 80 30 10
    scene add myPlanet
    myPlanet position cartesian 0 0 100
