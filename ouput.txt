Configuring the Web Server 
Digistar User's Guide / Scripting Reference / JavaScript Scripting / Javascript Web Scripting / Configuring the Web Server 
When the Digistar host is running, the web server is available by default. The system object has two attributes that deal with the web server: 
system web on/off 
This enables/disables all web access to the dshost machine, including the file server, and the HTTP web interface. 
system webInterface on/off 
This enables/disables the HTTP web interface on the dshost machine. The web interface allows retrieving and setting the data of objects on the system and executing Digistar commands. I this s off, then the Digistar Web 
JavaSeript functions will not work, neither will the HTTP Digistar commands. 
Configuring the http port 
By default the web server uses port 80 for all web access. If you have another application running on your Host machine that is using port 80, then you may need to change which port you are using. This can be changed by 
editing the <HTTPPort> field in the $Software/site/NetConfigm file. Changing this port will require you to change the URL that you are using o access Digistar web pages. For example if your new port numbet is 8080, 
then instead of http://192.168.2.99/digistar, you need to use the URL ht tp://192.168.2.99:8080/digistar
